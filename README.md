## Максим Малышев — ИИ-боты для бизнеса

Делаю ботов с ИИ для малого бизнеса: они отвечают клиентам по базе знаний и не выдумывают, записывают на свободное время, оценивают заявки и передают их в CRM.

Портфолио: **[nfbl.github.io](https://nfbl.github.io)** · Telegram: **[@nfbl_c](https://t.me/nfbl_c)**

### Готовые решения

Оба бота работают круглосуточно — их можно проверить в Telegram.

**01 · ИИ-администратор салона красоты**<br>
Ответы по прайсу, запись к мастеру, напоминания, живой администратор. Telegram и MAX с общим расписанием.<br>
Бот [@malyshev_lavanda_bot](https://t.me/malyshev_lavanda_bot) · код [salon-ai-admin-bot](https://github.com/nfbl/salon-ai-admin-bot)

**02 · ИИ-менеджер по продажам + Битрикс24**<br>
Квалификация заявки в диалоге, оценка лида 0–9, контакт и сделка в Битрикс24, карточка менеджеру.<br>
Бот [@malyshev_speakly_bot](https://t.me/malyshev_speakly_bot) · код [ai-sales-assistant-bot](https://github.com/nfbl/ai-sales-assistant-bot)

Решения показаны на вымышленных бизнесах — салоне «Лаванда» и онлайн-школе «Speakly» — и настраиваются под конкретную компанию за 1–5 дней.

### Стек

Python · aiogram 3 · MAX Bot API · SQLite · Битрикс24 REST API · Claude, GPT, Gemini, GigaChat · Linux, systemd
